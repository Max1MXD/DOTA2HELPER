# MVP

## Межа першого релізу

MVP — перша версія, яка дозволяє обрати героя та отримати базову рекомендацію по предметах з коротким поясненням. MVP перевіряє головну гіпотезу без одразу повного аналізу матчу та ігрового оверлею.

## Розкладка вимог за MoSCoW

### Must

- вибір героя та базових параметрів;
- безпечна валідація вхідних даних;
- рекомендація з поясненням;
- відображення версії даних;
- базовий тестовий набір та документація.

### Should

- урахування стадії матчу;
- кілька ролей;
- рекомендації по здібностях;
- попередження про застарілий патч.

### Could

- порівняння варіантів;
- експорт результату;
- додаткові налаштування інтерфейсу.

### Won't this time

- автоматичне керування персонажем;
- обхід античиту;
- непідтверджений оверлей;
- інтеграція із джерелами без дозволеного доступу.

## Схема шляху користувача

```
[Початок] → [Обрати героя] → [Вказати роль] → [Додати супротивників] → [Обрати стадію] → [Отримати рекомендації] → [Прийняти рішення]
```

## Критерії готовності MVP

- сценарій користувача працює від вводу до результату;
- вимоги та критерії прийняття записані;
- помилки вводу оброблені;
- тести проходять, а відомі дефекти зареєстровані;
- документація та версія ігрових даних оновлені;
- результат перевірено на прототипі зі зору зрозумілості.
