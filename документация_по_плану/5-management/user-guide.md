# User Guide — Інструкція користувача

> Для MVP-сценаріїв зі скріншотами прототипу та FAQ.

## Як користуватися

1. Відкрийте прототип (посилання в `README.md`).
2. На головному екрані оберіть героя зі списку (наприклад, Anti-Mage).
3. Оберіть роль (carry / mid / offlane / support / hard_support).
4. Додайте до 5 супротивників.
5. Оберіть стадію матчу (early / mid / late).
6. Вкажіть версію патча або залиште «Не перевірено».
7. Натисніть «Показати варіанти».

## Що бачить гравець

- Картки рекомендацій: назва предмета/здібності, пріоритет (1–5), коротке пояснення причини, версія даних.
- Попередження, якщо патч не підтверджено або дані застаріли.
- Повідомлення «Немає даних для обраного поєднання», якщо правил немає.

## FAQ

**Чи гарантує помічник перемогу?**
Ні. Рекомендації — це підказки, остаточне рішення приймає гравець.

**Чому вказується версія патча?**
Щоб ви розуміли, на яких даних базується порада. Якщо патч не підтверджено — довіра нижча.

**Чи можна грати з автоматичним керуванням?**
Ні. Автоматизація ігрових дій і обхід античиту заборонені.

**Що робити, якщо немає даних для мого героя?**
Спробувати інший набір параметрів або зачекати оновлення даних.

**Чи зберігаються мої дані?**
Ні. Збирається мінімум даних, історія запитів ≤ 30 днів (див. `privacy.md`).
