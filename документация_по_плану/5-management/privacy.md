# Privacy — Політика конфіденційності

## Які персональні дані збираються

- **Не збирається** ідентифікатор акаунту Steam, IP, email, точне місцезнаходження.
- Зберігається лише мінімум: параметри запиту (герой, роль, супротивники, стадія, патч) для покращення рекомендацій.

## Навіщо

- Для генерації ситуаційних рекомендацій.
- Для аналізу популярності запитів (агреговано, без ідентифікації).

## Скільки зберігаються

- Історія запитів: ≤ 30 днів, після чого видаляється або агрегується.
- Агрегована статистика: ≤ 12 місяців.

## Як видалити

- Написати на GitHub Issues з проханням видалити історію запитів.
- Видалення виконується ≤ 7 днів.

## Обмеження

- Помічник не грає замість користувача.
- Автоматизація ігрових дій, обхід античиту та непідтверджений доступ до даних заборонені.
- Рекомендації не є гарантією перемоги.

## Згоди

Використовуючи прототип, ви погоджуєтесь з обробкою мінімуму даних, описаним у цьому документі.
