# User Flow — Прототип головного шляху користувача

## Екрани

### 1. Початковий екран (Empty Form)

```
┌─────────────────────────────────────┐
│  ШІ-помічник для Dota 2             │
├─────────────────────────────────────┤
│  Герой:    [Вибрати героя      ▼] * │
│  Роль:     [Вибрати роль       ▼]   │
│  Супротивники (макс 5):             │
│    [+ Додати супротивника]          │
│  Стадія:   [Рання ▼]                │
│  Патч:     [7.37d / Не перевірено]  │
│                                     │
│  [Показати варіанти]  (неактивна)   │
└─────────────────────────────────────┘
```

- Поля з * — обов'язкові.
- Кнопка активна лише при заповненні обов'язкових полів.
- Версія патчу: вибір зі списку підтверджених або «Не перевірено».

## Переходи між екранами

```
[Empty Form] --(valid submit)--> [Loading] --(success)--> [Success]
                                     \--(no data)--> [No Data]
                                     \--(stale)--> [Stale Patch]
                \--(invalid)--> [Validation Error] --(fix)--> [Empty Form]
[Stale Patch] --(show anyway)--> [Loading] --(...)
[Success] --(change params)--> [Empty Form]
```

## Карта екранів

| Екран | ID | Передумови | Наступні можливі стани |
|---|---|---|---|
| Empty Form | S0 | Початковий | Loading, Validation Error |
| Loading | S1 | Валідний запит | Success, No Data, Stale Patch, Error |
| Success | S2 | Дані знайдено | Empty Form (зміна параметрів) |
| Validation Error | S3 | Невалідна форма | Empty Form (після виправлення) |
| No Data | S4 | Правил немає | Empty Form |
| Stale Patch | S5 | Патч не підтверджено | Loading (show anyway), Empty Form |
| Error | S6 | Помилка сервера/мережі | Empty Form (retry) |

## Перевірка прототипу

Порівняти компактний варіант з розширеним вікном та перевірити, чи може гравець без підказки обрати героя, зрозуміти причину рекомендації та помітити версію патча. Результати тесту фіксуються в `4-quality/usability-test.md`.
