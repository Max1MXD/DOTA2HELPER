# ADR-0003: Валідація — Zod для схем

## Контекст

Потрібно обрати бібліотеку для валідації вхідних даних (MatchContext) і схем відповідей API.

## Варіанти

| Варіант | Плюси | Мінуси |
|---|---|---|
| Zod | TypeScript-first, inference типів, компактний, популярний | Залежність від npm |
| Valibot | Менший розмір, модульний, схожий API | Молодший, менше екосистеми |
| Joi | Зрілий, потужний | Важчий, не TypeScript-native |
| Custom | Жодних залежностей | Потрібно писати і підтримувати |

## Рішення

**Обрано: Zod** — найкращий баланс TypeScript інтеграції, розміру та зрілості для навчального проєкту.

## Наслідки

- Схеми `MatchContext`, `RecommendationResponse` описані в Zod.
- Типи TypeScript інферяться автоматично.
- Валідація на клієнті (UI) і сервері (API) — одна схема.
