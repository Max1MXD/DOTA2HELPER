# Test Plan — Тестування

> Спрощено за ISO/IEC/IEEE 29119-3.

## Рівні тестування

| Рівень | Що тестується | Інструмент | Автоматизація |
|---|---|---|---|
| Модульне | Операції з `api.md`, Validator, Engine | Vitest / Jest | Так |
| Інтеграційний | Стики між модулями (`integration-plan.md`) | Supertest + mock Data Store | Так |
| Системний | Повний шлях на прототипі | Ручне тестування прототипу | Ні |
| Приймальне | Must-вимоги SRS | Критерії приймання `srs.md` | Ні |

## Верифікація vs Валідація

- **Верифікація:** чи правильно реалізовано вимоги та правила розрахунку.
- **Валідація:** чи допомагає результат гравцеві прийняти рішення та зрозуміти пояснення.

## Критерії входу

- Схема API (`api.md`) затверджена.
- Правила валідації (`validation-rules.md`) затверджені.
- Прототип доступний для системного тестування.

## Критерії виходу

- Усі Must-вимоги мають принаймні один тест-кейс.
- Критичні дефекти закриті або прийняті власником продукту.
- Версія ігрових даних вказана.

## Покриття

- 25+ тест-кейсів, з них ≥ 10 негативних.
- Класи еквівалентності та межові значення для полів валідації.
